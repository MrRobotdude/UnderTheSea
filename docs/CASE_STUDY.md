# UnderTheSea

**Desktop training project · Doddie Prawarjito**

## Problem

A WPF exercise in organizing multiple departments and operational workflows.

## Contribution

The author reports implementing the complete project. Third-party libraries, UI foundations, and historical academic credits retain their attribution. This case study makes no claim about business impact without measured evidence.

## Design and engineering

Caliburn.Micro view conventions separate presentation from view-model behavior, while Dapper maps relational data into domain objects.

## Current limits

The original database and stored procedures are lost. A separate synthetic ticketing demo has been reconstructed; other departments are not restored. This is a legacy learning example with remaining authentication/data-access modernization work.

## Demonstration

Use the documented LocalDB ticketing demo to explain login, ticket state transitions, and the view/model structure.

The README describes setup. Validation results from this preparation are recorded in the local portfolio preparation report; feature descriptions alone are not test evidence.
